# Áudio — Fase 1

Coloque aqui a trilha principal da Fase 1 com o nome exato:

`phase1-theme.mp3`

O jogo já está configurado para:
- iniciar a música quando o jogador clicar em **Iniciar Jornada**;
- tocar em loop;
- reduzir o volume automaticamente durante diálogos;
- restaurar o volume depois das falas;
- permitir ligar/desligar a música pelo botão no HUD;
- salvar a preferência de áudio no navegador;
- fazer fade-out ao concluir a fase.

Futuramente, a música do chefão poderá ser adicionada nesta mesma pasta como `phase1-boss.mp3`.

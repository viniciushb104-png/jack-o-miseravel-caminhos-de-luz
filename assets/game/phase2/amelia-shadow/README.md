# Amélia Vesper — Sombra / Boss

Estrutura oficial dos assets da revelação do chefão da Fase 2.

```
amelia-shadow/
├── dialogue/        # 8 retratos novos para a conversa da revelação
├── transformation/  # 12 frames: dor → sombra → separação
├── boss/            # 9 poses da Sombra de Amélia
├── atlases/         # 3 atlases opcionais
├── reference/       # folha conceitual completa
├── amelia-shadow-boss.json
└── README.md
```

Cada subpasta contém um `README.md` com **os nomes exatos dos arquivos que pertencem nela**.

Ao extrair `amelia-vesper-shadow-boss-pack.zip`, entre na pasta extraída e distribua os arquivos conforme essas subpastas. Não crie uma segunda pasta `amelia-vesper-shadow-boss-pack` dentro desta.

## Arquivos da raiz

Depois das subpastas, coloque diretamente nesta pasta somente:
- `amelia-shadow-boss.json`
- opcionalmente `PREVIEW.png`

A folha conceitual vai em `reference/`, e não na raiz.

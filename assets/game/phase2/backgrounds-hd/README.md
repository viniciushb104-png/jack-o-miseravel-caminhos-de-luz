# Fundos HD — Halloween II

## Arquivo de referência principal
Envie aqui com o nome:

`phase2-vila-torre-background-reference.png`

A imagem reúne a linguagem visual aprovada para os dois grandes ambientes da fase:
- Vila sem Amanhecer: Halloween gótico, relógios derretendo, 4:13, estátuas/pessoas congeladas no tempo.
- Torre das 4:13: arquitetura vertical, engrenagens, relógios, pontes e figuras congeladas.

Depois da imagem estar nesta pasta, o jogo poderá usá-la como referência/asset para substituir o cenário procedural do protótipo por fundos HD.

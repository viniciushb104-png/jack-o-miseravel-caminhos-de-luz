# Vídeo do menu

Coloque aqui o vídeo animado exportado do Gemini.

Nome principal obrigatório:

```
jack-menu-bg-loop.mp4
```

Caminho final usado pelo site:

```
assets/videos/menu/jack-menu-bg-loop.mp4
```

Opcionalmente, você também pode adicionar:

```
jack-menu-bg-loop.webm
```

O site tenta carregar primeiro a versão WebM e depois a MP4. Se nenhum vídeo estiver presente, o poster estático em `assets/images/menu/menu-poster.webp` aparece automaticamente.

Recomendado: 16:9, loop de 5–10 s, sem áudio, 1280×720 ou 1600×900, movimento suave e sem alterar o enquadramento.
